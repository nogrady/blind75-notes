Blind 75 中文教程

这套教程用 75 道题练习可迁移的解题能力。每题提供中文推导、正确性理由、边界情况，以及 Python、Java、C++、Go 四种实现。先选一门语言独立完成，再对照其他语言；第一轮不必把同一道题写四遍。

适合已经理解变量、循环、函数和基本容器，准备系统练习算法的人。如果递归、复杂度或指针还不熟悉，先读下面的基础约定，再从两数之和与反转链表开始。

题目范围采用经典 Blind 75 分类清单，合并 K 个有序链表只计一次。题单出处见 Blind 75 作者说明及作者链接的 75 题分类清单。讲解、模板与示例实现是为本教程编写的；题意为学习用简述，完整约束以各题链接为准。

怎么学一题

  1. 复述问题。 输入是什么，返回什么，是否允许修改输入，重复值与空输入是否合法？
  2. 写一个小例子。 自己算出答案，再造一个能使直觉失败的反例。
  3. 先说暴力解。 找出重复的查找、重复的遍历或重复的子问题。
  4. 命名状态。 例如 seen 表示已经扫过的值，dp[i] 表示前 i 个元素的答案。状态定义不能写完代码才补。
  5. 写不变量。 不变量就是每轮循环或每次递归前后一直成立的事实。它解释了为什么可以排除一批候选答案。
  6. 写代码与测试。 正常、最小、重复、极端形状各考虑一次。不要只运行题目示例。
  7. 闭卷总结。 用三句话说明识别信号、核心状态和最容易错的边界，再完成一次变式练习。

第一次接触一道题，可以先独立思考 20 分钟；卡住后只看「识别信号」，再看「推导」，最后才看代码。第二天闭卷重做，之后可在第 3、7、14 天复习；这是可调整的练习安排，不是固定的记忆规律。

四语言阅读约定

建议使用 Python 3.10 或更新版本、Java 11 或更新版本、C++17、Go 1.21 或更新版本。部分 Go 解答使用内置 min 和 max。

每道题是一份独立程序片段，不能把多个同名 Solution 直接拼在一起。为本地阅读，部分代码包含 ListNode、TreeNode 或图节点定义；提交到已经提供这些类型的平台时，保留平台类型，移除重复定义。Go 的 package main 与导入声明适用于独立文件；提交时按题目编辑器的框架调整。

四种语言尽量实现同一算法；接口、容器和少数语言细节可以不同。复杂度栏主要分析 Python 主实现，语言差异栏说明可能改变复杂度的因素。哈希表查找的 O(1) 均指平均情况。空间复杂度通常区分辅助空间和返回结果，递归调用栈必须计入。

排序的辅助空间因语言库而异：Python 的排序最坏需要 O(n) 辅助空间，C++ 常用排序的栈空间为 O(log n)，Java 对象数组排序与基本类型数组排序不同。不要看到「原地排序调用」就统一写 O(1)。字符串切片、拼接和哈希也可能与字符串长度成正比。

C++ 按值接受 string 可能产生 O(n) 的参数副本；需要精确控制辅助空间时可改成合适的 const string& 接口。第 49 题的 C++ 分组结果复制字符串内容，因此还要计入总字符数 S 对应的 O(S) 空间。Java 的 toCharArray() 会创建字符数组；Go 的子串切片通常不复制底层字节，但可能使整段原字符串继续占用内存。这些差异不会改变核心算法，却可能改变辅助空间。

第 190 题 Java 返回的是 int 中保存的 32 位结果。最高位为 1 时，直接打印会看到负数；需要显示无符号数值时使用 Integer.toUnsignedLong(result)。

复杂度怎样计算

n 常表示元素个数，V/E 表示图的点数与边数，h 表示树高，R/C 表示矩阵行列数。嵌套循环不一定是 O(n²)：滑动窗口中左右指针各最多移动 n 次，合计 O(n)。递归深度也不等于总运行时间：分支数为 2、深度为 n 的递归搜索树，可能包含 O(2^n) 次调用。

对于输出所有组合的题，答案本身可能很大，应说明结果数量或搜索树大小；对 DFS，要分别计算访问次数和同时存在的栈帧。对字符串 DP，要检查每次切片、哈希或比较的成本。

三个完整的思考过程

从两层循环到哈希查找

两数之和中，固定当前数 x 后，另一个数必须是 target-x。暴力解反复扫描过去的元素，重复的是「这个数是否出现过」。把过去的值及下标放进字典，就把一次线性搜索换成平均常数时间查找。

例如 [4, 1, 7]，目标为 8：看到 4 时查 4，不存在，再保存 4；看到 1 时查 7，不存在，再保存 1；看到 7 时查 1，找到下标 1。查找发生在保存当前元素之前，因此不会把同一个位置使用两次。可迁移的思想是：明确缺什么，再为过去的信息建立索引。

从重复枚举到滑动窗口

无重复字符的最长子串中，窗口只关心当前左右边界之间的字符。例子 abba：加入第一个 b 后窗口为 ab；再加入 b 出现重复，移走 a 仍然重复，还要移走旧 b，窗口才重新合法；最后加入 a，得到 ba。这说明恢复合法性通常需要 while，不能凭直觉只缩一次。

最小覆盖子串的方向不同：先扩张到覆盖目标，再尽量收缩；收缩前记录答案，因为移除关键字符后会失去覆盖。最长问题通常在恢复合法后记录，最短覆盖通常在合法期间持续记录。不要把两者的更新时机机械混用。

从选择树到动态规划

打家劫舍中，面对当前房屋只有「不偷」和「偷」两种选择。定义 dp[i] 为前 i 间房的最大收益：不偷第 i 间得到 dp[i-1]；偷它就必须跳过相邻房，得到 dp[i-2] + nums[i-1]。取两者最大值。

对 [2, 7, 9, 3, 1]，前缀最优值依次为 0, 2, 7, 11, 11, 12。最后一项只依赖前两项，所以可以压缩空间；压缩前必须先理解数组版本，更新时也不能把旧值提前覆盖。可迁移的思想是：先定义子问题，再写互斥且完整的最后一步选择。

判断自己是否真的掌握

能读懂代码是起点。能闭卷写出、解释为什么正确、给出边界反例、处理一项约束变化，才算本轮掌握。遇到变式时先重新检查不变量，不必强行套原题的写法。

建议记录四种状态：待学、已理解、独立完成、需要复习。网页阅读版会在浏览器允许时保存状态；重要的复盘可另存到自己的笔记中。

可复用解题模板

以下是与语言无关的思考骨架。代码块使用伪代码，含有需要按题意填写的条件，不应直接提交。四种语言的完整实现见对应题目。

1 哈希索引与频次

适用信号： 重复判断、补数查找、频率统计、相同特征分组。先明确键代表什么：原始值、排序后的字符串，还是频次向量。

建立 空表
依次读取 当前元素 x：
    查询与 x 匹配的历史信息
    如满足目标，记录答案
    更新 x 对应的信息

不变量： 表中只包含已经处理的元素。两数之和要先查后存；字符频次题则可能先全部计数再比较。分组的键必须让同组元素拥有同一个规范表示。

迁移链： 1 → 217 → 242 → 49 → 128。反例提醒： 同一个数出现两次，并不等于同一个下标可以使用两次。

2 前缀与后缀

适用信号： 每个位置需要「它之前」与「它之后」的信息；区间查询可由两个前缀相减。

prefix[0] = 运算的单位元
for i 从左到右：
    prefix[i+1] = combine(prefix[i], a[i])
从右向左维护 suffix：
    answer[i] = combine(prefix[i], suffix)
    suffix = combine(a[i], suffix)

不变量： 计算 answer[i] 时，两边都不包含 a[i]。求和单位元为 0，求积为 1。区间和支持相减，但区间最小值通常不能用两个前缀最小值相减恢复。

代表题： 238。反例提醒： 出现 0 时，先求总乘积再除以当前数的方案失效。

3 相向双指针

适用信号： 排序后的配对、两端约束、回文检查。指针移动必须能解释为什么一批候选不可能更优。

left = 0，right = n-1
while left < right：
    评估当前候选
    根据可证明的排除条件：
        left += 1 或 right -= 1

不变量： 尚未排除的答案在当前范围内。两数和偏小则移左指针；容器题则移动较短边，因为固定短边并缩小宽度不可能增加面积。这两种证明不同。

迁移链： 125 → 11 → 15。反例提醒： 排序会改变下标；三数之和需要同时处理外层与内层去重。

4 最长合法滑动窗口

适用信号： 连续区间，加入右端可能破坏条件，移除左端能逐步恢复。

left = 0
for right 从左到右：
    加入 a[right]
    while 当前窗口不合法：
        移除 a[left]
        left += 1
    更新最长答案

不变量： 更新答案时窗口合法。左右边界只前进，各最多走 n 次。这里是严格合法窗口模板；使用历史最大频率的第 424 题优化写法，需要单独证明，不能直接声称当前窗口始终合法。

迁移链： 3 → 424。反例提醒： 含负数的区间和，不一定具有可通过固定方向收缩恢复的单调性。

5 最短覆盖滑动窗口

left = 0
for right 从左到右：
    加入 a[right] 并更新满足情况
    while 已满足全部需求：
        更新最短答案
        移除 a[left] 并更新满足情况
        left += 1

不变量： 每次记录时已经满足所有需求。目标有两个 A 时，必须覆盖两个 A；「出现过几种字符」不能代替「满足了几种字符的所需次数」。

代表题： 76。反例提醒： 去掉左边界之后才记录，可能把已经不合法的窗口当作答案。

6 二分边界

适用信号： 条件在搜索范围内呈现假到真的分界，或每次能证明一半范围可排除。

left = 0，right = n          # 半开区间 [left, right)
while left < right：
    mid = left + (right-left)//2
    if 条件(mid) 为真：right = mid
    else：left = mid + 1
return left                  # 第一个为真的位置，可能是 n

不变量： 左边已确定为假，右边已确定为真。旋转数组不能直接对数值大小套这个模板，必须先判断哪一半有序。第 153 题的最小值搜索使用另一套闭区间规则，也应保持自己的边界约定。

迁移链： 153 → 33 → 300 的进阶优化。反例提醒： left = mid 在两个元素时可能不前进。

7 链表局部改线

prev = 空
cur = head
while cur 非空：
    next = cur.next           # 先保存未处理部分
    cur.next = prev
    prev = cur
    cur = next
return prev

不变量： prev 是已经反转的前缀，cur 是尚未处理的后缀。删除与合并可加哑节点，让修改头节点和修改中间节点使用同一套规则。

迁移链： 206 → 21 → 19 → 143。反例提醒： 改写 next 后才尝试寻找后继，可能丢失整条后缀。

8 快慢指针

slow = head，fast = head
while fast 非空 且 fast.next 非空：
    slow = slow.next
    fast = fast.next.next
    按题意处理相遇或中点

不变量： 快指针移动速度是慢指针两倍。找环看节点身份，不比较节点的值；找中点时，要明确偶数长度希望停在左中点还是右中点。

迁移链： 141 → 143。反例提醒： 固定间隔双指针与快慢指针不同：删除倒数第 n 个节点先建立 n 个节点的距离，再同速前进。

9 区间排序与扫描

合并区间： 按起点排序，维护最后一个合并区间的最远终点；当前起点没有越过它就合并。最多兼容区间： 按终点排序，优先保留最早结束的区间；这给后续留下最多空间。

按所需的键排序
for 当前区间：
    if 与维护中的状态冲突：合并、丢弃或增加资源
    else：接受新区间并更新状态

迁移链： 56 → 57 → 435 → 252 → 253。反例提醒： 闭区间合并中 [1,2] 与 [2,3] 可以合并；会议结束于 2，下一场开始于 2，通常可以共用会议室。边界由题意决定。

10 树的递归返回值

solve(node)：
    if node 为空：返回空树的基准答案
    left = solve(node.left)
    right = solve(node.right)
    用 left、right、node 更新当前节点的答案
    返回父节点真正需要的摘要

不变量： 调用结束时，返回值完整表达该子树的指定信息。最大路径和中，全局答案可以连接左右分支；返回给父亲的只能是一条向下链，不能带着一个分叉继续向上。

迁移链： 104 → 100 → 226 → 98 → 124。反例提醒： 验证 BST 需要祖先给出的完整上下界，仅比较父子节点不够。

11 BFS 分层与最短步数

起点入队，并立刻标记已访问
while 队列非空：
    本层数量 = 当前队列长度
    重复 本层数量 次：
        取出节点
        for 每个未访问邻居：
            标记，然后入队

不变量： 无权图中，队列按离起点的距离逐层扩展。入队即标记避免同一节点反复入队。树的层序遍历可省略访问集合，因为结构本身没有回边。

迁移链： 102 → 200 → 417。反例提醒： 不同边权的最短路不能直接用普通 BFS；第 417 题要从海岸向更高处反向搜索。

12 拓扑排序

为全部节点建立邻接表与入度
所有入度为 0 的节点入队
while 队列非空：
    弹出 u，加入顺序
    for u -> v：
        indegree[v] -= 1
        if indegree[v] == 0：v 入队
若输出节点数小于总节点数：有环

不变量： 只有所有前驱都已处理的节点才会出队。字典顺序推断中，相邻单词只有首个不同字符产生边；遇到长词排在自己的短前缀之前，要直接判无解。

迁移链： 207 → 269。反例提醒： 去重边与入度更新要一致；独立节点也必须进入图。

13 并查集

parent[i] = i，size[i] = 1，components = n
find(x)：沿父指针找根，并压缩路径
union(a, b)：
    ra = find(a)，rb = find(b)
    if ra == rb：返回「已经连通」
    把较小集合的根接到较大集合根下面
    更新 size 与 components

不变量： 同根等价于目前处理过的边已经连通。配合按大小合并与路径压缩，多次操作摊还接近常数，即 O(α(n))。

迁移链： 323 → 261。反例提醒： 并查集负责连通性，不保存实际路径，也不能直接判断有向图依赖环。

14 回溯与恢复

search(状态, 路径)：
    if 已完成：保存路径副本；返回
    for 每个合法选择：
        做选择，更新状态
        search(新状态, 路径)
        撤销选择，恢复状态

不变量： 一个分支结束后，环境恢复到进入它之前。组合使用起始下标消除排列重复；允许重复选同一候选时，递归传当前下标，否则传下一个下标。

迁移链： 39 → 79 → 212。反例提醒： 保存同一个可变列表的引用会导致所有答案一起变化；全局 visited 不适合表示单条路径的占用状态。

15 动态规划五问

依次回答：状态是什么？从哪里转移？初始值是什么？按什么顺序计算？答案在哪里？

初始化所有状态为「不可达」或明确的基准值
按依赖顺序遍历状态：
    枚举合法的最后一步
    从更小子问题合成当前答案
返回目标状态

代表状态： dp[i] 为前 i 个字符能否切分；dp[a] 为组成金额 a 的最少硬币数；dp[i][j] 为两段前缀的最长公共子序列长度。最少个数的不可达值可用正无穷，不能默认填 0。

迁移链： 70 → 198 → 213 → 322 → 139 → 91 → 1143。反例提醒： 计数题中交换循环顺序可能把组合改成排列。求 LIS 时的「以 i 结尾」也不能写成「前 i 个」后照搬转移。

16 贪心与交换理由

适用信号： 能证明一个局部选择不会降低某个最优解，而不是仅仅观察样例都成功。

维护可达边界或当前最优资源状态
按顺序处理候选：
    验证当前候选仍可到达或可接受
    采用不会使未来更差的选择
    更新边界

代表题： 55、435、121。跳跃游戏只需知道最远可达位置，无需枚举每条路径；区间调度选择最早结束者，可以用交换论证保留后续可行性。

反例提醒： 硬币 [1,3,4] 组成 6，先取最大硬币得到 4+1+1，但最优是 3+3；硬币问题不能随便贪心。

17 堆与有序边界

前 K 个： 用大小不超过 K 的最小堆保留当前最大的 K 个候选，堆顶是最容易被淘汰的元素。多路合并： 每路只放当前头元素，取出后补入该路下一个。中位数： 最大堆保存较小一半，最小堆保存较大一半。

不变量： 堆只保证顶部极值，不保证所有元素遍历有序。双堆还要保证大小相差至多 1，并且左半最大值不超过右半最小值。

迁移链： 347 → 23 → 295 → 253。反例提醒： Python 的 (值, 节点) 在值相等时可能比较不可排序的节点，应加入唯一编号。

18 Trie 前缀状态

适用信号： 反复查找前缀、多词共享前缀、网格中同时搜索很多单词。

根到节点的一条路径代表一个前缀；terminal 区分完整单词与仅有前缀。插入时按字符逐步建立子节点；查询时沿相同路径前进。通配符匹配需要探索多个子节点，最坏不是 O(单词长度)。

不变量： 当前节点对应已经匹配的完整前缀。迁移链为 208 → 211 → 212。反例提醒： Trie 的「前缀存在」不等于「单词存在」；找到一个单词后，仍可能沿同一前缀继续找到更长的单词。

19 位运算与固定位宽

n & (n-1) 删除最低位的 1；a ^ b 做无进位加法；(a & b) << 1 产生进位。计数题中每次删除一位 1，状态严格缩小；加法题中每轮保持结果与剩余进位的总和不变。

Python 处理负数的固定宽度加法要做掩码；Java 右移要区分 >> 与 >>>；C++ 应在无符号类型上完成需要回绕的位操作。迁移链为 191 → 338 → 190 → 371。

反例提醒： 任意精度整数的负数不能当成天然只有 32 位；颠倒二进制位必须保留原来的前导零位置，不能只反转有效位。
